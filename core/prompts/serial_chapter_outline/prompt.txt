【生成要求】
为本章写一份完整的章纲，包含以下 8 个要素。每个要素使用 # 标题作为独立段落，段落之间空行：

# 主线与状态
主角（或视角人物）当前处于什么处境、面临什么核心矛盾或驱动力。不要以"本章开头"起头，直接描述人物状态和所处困境。

# 事件流
按因果逻辑叙述核心事件，以"发生了什么 → 人物如何反应 → 导致什么结果"为基本单元。标注转折点（计划被打断、意外发生、真相揭露等）。提取角色在对话或行动中使用的具体策略、话术、心理战术。
以事件和因果为节点推进，不以时间段（清晨/上午/下午/傍晚）作为事件编号的起点。时间只在对情节有意义时自然带出，不作为每个事件的标签。

# 关键细节
推动情节发展的具体内容，包括：
关键对话：必须写出具体内容（谁说了什么），不要概括为"说了xxx"。
关键行动：角色的具体行为及其直接后果。
关键发现：角色获得的重要信息、物品、线索。
关键决策：角色做出的重要选择及其理由。
内心活动：角色的内心独白、潜意识反应。
隐藏动机：角色抱怨、嫉妒、敌意等负面情绪的真实来源。

# 情绪走向
视角人物的情绪变化脉络。标注关键情绪节点（如危机感、疑惑、震惊、释然等），以及情绪转折的具体触发原因。

# 伏笔与信息差
本章新埋的伏笔、回收的前文伏笔、谁知道了什么而谁还不知道。

# 章末钩子
本章结尾停在什么位置。读者此刻最想知道什么、最担心什么。标注钩子类型（悬念/危机/反转/新谜题）。

# 本章角色
列出本章出场的所有角色：姓名、本章中的身份、与主角关系。

# 本章世界观元素
本章涉及的世界观相关内容：力量体系、组织体制、地名、技能/法术/特殊能力使用等。

每章章纲 800-1500 字。

【输出格式】
使用纯文本输出，禁止使用 Markdown 格式符号（如 *、**、-、>、| 等）。

格式要求：
每一章的章纲必须以【第X章 章纲】开头。
8 个要素段落每个都以 # 标题 开头，段落之间空一行。

正确格式示例（以下内容仅演示结构，与你的小说题材、设定无关，严禁照搬其中的人名、称谓、设定词）：

【第1章 章纲】
# 主线与状态
主角艾登穿越进入魔法学院，发现自己被分配到条件最差的助理生宿舍，学院等级体系对他毫无优待。

# 事件流
正当他摸清学院规则时，同届学长布莱克一身伤痕出现，告诉他自己上了院长秘密名单。不等细问，布莱克飞奔离开。他正犹豫要不要跟上，学院广播宣布图书馆禁书室失窃，嫌疑人正是布莱克。巡查员问他是否见过布莱克，他当即否认。回到宿舍准备收拾行李，打开房门，房内竟散发出一道诡异的蓝色光芒。

# 关键细节
布莱克说"院长每个月从助理生里挑三个人，送到北塔那个地方，去了的再没回来过"。艾登决定先装作不知情再找机会离开。

# 情绪走向
得意→危机感→疑惑→震惊

# 伏笔与信息差
布莱克提到的"北塔那个地方"尚未解释。艾登知道秘闻但巡查员不知道。

# 章末钩子
房内蓝光是何物？名单是真是假？（反转/悬念）

# 本章角色
艾登（主角，魔法学院助理生）、布莱克（高年级学生，告知艾登秘闻后逃离）、巡查员（学院执法人员）

# 本章世界观元素
星光学院（组织）、助理生/普通生/荣誉生（学院等级）、禁书室（地点）
