# 风格强度控制 - 使用指南

## 功能说明

允许用户自定义风格保留程度（0-100%），在"完全遵循参考书"和"自由创新"之间灵活调节。

---

## 快速开始

### 1. 查看当前配置

```bash
novel style-config my-novel
```

输出：
```
当前风格配置：
  风格保留度：80%（默认）
```

### 2. 设置风格强度

```bash
# 90% 参考风格（接近完全复刻）
novel style-config my-novel --intensity 90

# 50% 参考风格（各半）
novel style-config my-novel --intensity 50

# 30% 参考风格（大胆创新）
novel style-config my-novel --intensity 30
```

### 3. 指定灵活/严格方面

```bash
# 对话可以现代化，但其他保持原风格
novel style-config my-novel --intensity 80 --flexible "对话风格"

# 禁忌词汇必须严格遵守
novel style-config my-novel --intensity 70 --strict "禁忌词汇"

# 组合使用
novel style-config my-novel \
  --intensity 75 \
  --flexible "对话风格,句式节奏" \
  --strict "禁忌词汇,对话标记"
```

---

## 强度等级说明

| 强度 | 等级 | 说明 | 适用场景 |
|---|---|---|---|
| 90-100% | 极高 | 严格遵循所有风格特征 | 想完全复刻参考书的文风 |
| 70-89% | 高 | 保持主要风格，允许少量创新 | 保留参考书特色，微调细节 |
| 50-69% | 中等 | 保留核心风格，适度融入新元素 | 平衡参考与创新 |
| 30-49% | 低 | 仅保留核心风格，大部分自由发挥 | 只借鉴参考书的精髓 |
| 0-29% | 极低 | 参考风格仅供借鉴，可大胆创新 | 基本自由创作 |

---

## 可配置的方面

### 允许灵活处理（--flexible）

- **对话风格**：可以更现代化（如：把文言对话改为白话）
- **句式节奏**：可以调整长短句比例
- **描写密度**：可以增减环境/动作/心理描写
- **叙述视角**：可以改变人称（第一/第三）

### 必须严格遵循（--strict）

- **禁忌词汇**：不能使用参考书中避免的词（如"心中暗想"）
- **对话标记**：必须使用指定符号（如「」）
- **人称视角**：不能改变人称
- **叙事节奏**：必须保持快/慢节奏

## 使用示例

### 场景 1：完全复刻参考书

```bash
# 设置 95% 强度
novel style-config my-novel --intensity 95

# 生成时效果
novel write my-novel --volume 1
```

**生成结果**：
```
他握剑的手微微颤抖。     # 参考书：用动作暗示，不直说
「杀。」                 # 参考书：用「」，对话极简
剑起。血落。人亡。       # 参考书：三连短句
```

---

### 场景 2：现代化改编

```bash
# 参考书：古风修仙，对话文言
# 新小说：现代都市异能，对话需现代化

novel style-config my-novel \
  --intensity 70 \
  --flexible "对话风格" \
  --strict "禁忌词汇,叙事节奏"
```

**生成结果**：
```
他握手机的手微微颤抖。         # 保留：动作暗示（不用"心中暗想"）
"干掉他。"                    # 灵活：对话现代化（不用「」）
拳出。风鸣。人倒。            # 保留：三连短句节奏
```

---

### 场景 3：保留精髓，大胆创新

```bash
# 只保留参考书的"短句快节奏"和"不用禁忌词"
novel style-config my-novel \
  --intensity 40 \
  --strict "禁忌词汇"
```

**生成结果**：
```
他看着对方，眼神冷漠。       # 创新：长句描写（参考书用短句）
"你想怎么样？"他问道。      # 创新：对话符号（参考书用「」）
对方没有回答。                # 保留：不用"心中暗想"
```

## 实现原理

### 配置存储

```json
// my-novels/my-novel/style_config.json
{
  "style_intensity": 75,
  "flexible_aspects": ["对话风格", "句式节奏"],
  "strict_aspects": ["禁忌词汇"]
}
```

### Prompt 调整

**强度 90%**：
```
【写作风格控制】
风格保留度：90%（极高）
必须严格遵循参考小说的所有风格特征，不允许任何偏离。
```

**强度 50%**：
```
【写作风格控制】
风格保留度：50%（中等）
在保留参考小说风格基础上，可以适度融入新元素。

【允许灵活处理的方面】
- 对话风格：可以更现代化

【创新空间】（50%）
在不违背上述要求的前提下，可以：
- 调整对话风格以适应现代读者
- 增加或减少描写密度
```

## 注意事项

### 1. 配置后生效时机

```bash
# 配置后立即生效
novel style-config my-novel --intensity 60

# 下次生成时应用新配置
novel write my-novel --volume 1
```

### 2. 中途修改配置

```bash
# 已生成第 1-10 章（强度 80%）
# 想修改第 11-20 章的强度

novel style-config my-novel --intensity 50
novel write my-novel --volume 1 --start 11 --max 10
```

**建议**：整卷使用统一强度，避免前后风格差异过大

### 3. 无风格指南时

如果没有提取参考书风格（`STYLE_GUIDE.md` 不存在），风格强度配置不生效，使用默认规范。

## 高级用法

### 分卷设置不同强度

```bash
# 第1卷：严格遵循（铺垫阶段）
novel style-config my-novel --intensity 90
novel write my-novel --volume 1

# 第2卷：适度创新（发展阶段）
novel style-config my-novel --intensity 70
novel write my-novel --volume 2

# 第3卷：大胆创新（高潮阶段）
novel style-config my-novel --intensity 50
novel write my-novel --volume 3
```

### 结合创作方向

```bash
# 创作方向
echo "改编为现代都市，保留原书的简洁文风和快节奏" > creative_direction.md

# 风格配置
novel style-config my-novel \
  --intensity 70 \
  --flexible "对话风格,描写密度" \
  --strict "叙事节奏,禁忌词汇"

# 生成时两者结合
novel novel-outline my-novel
```

## 总结

| 需求 | 配置 |
|---|---|
| 完全复刻参考书 | `--intensity 95` |
| 保留特色，微调 | `--intensity 80 --flexible "对话风格"` |
| 现代化改编 | `--intensity 70 --flexible "对话风格,描写密度"` |
| 只借鉴精髓 | `--intensity 40 --strict "禁忌词汇"` |
| 基本自由创作 | `--intensity 20` |

这个功能让用户可以精确控制"模仿"与"创新"的平衡。
